# Paper Studio Demo

Scaffolded brand directory. Before any delivery:

1. Confirm the palette with the owner (background/text/neutral are placeholders around the supplied accent).
2. Add licensed fonts under `media/fonts/` and register them in `brand.json` identity.
3. Only add media with documented rights in `licensing/` (source + license + review date).
4. Keep project manifests under `projects/`; brand paths are relative to this directory.
