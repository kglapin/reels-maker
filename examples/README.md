# Manual narration-cue demo (no licensed source bundled)

This is a **schema example**, not a renderable ASTA campaign:
`source-unbranded.mp4` is an intentionally nonexistent placeholder and must
be replaced with licensed clean footage after source review. The composition
demonstrates subtitle entrances anchored to verified **scene-local**
narration/beat timecodes. No captions are extracted or synthesized by AI.
Inspect `docs/MOTION_DESIGN.md` for allowed cue fields and constraints.

To run, replace the source with an unbranded accessible MP4 and validate
its copyright/usage rights; run `validate --syntax-only --strict-quality`
first, then media preflight and rendering. The engine retains all sizes in
the project, not in the brandbook.
